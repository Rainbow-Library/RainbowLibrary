# Privacy Policy – TransVoice

**Last Updated: September 2026**

TransVoice, developed and provided by the Rainbow Library, is committed to protecting the privacy of its users. Respect for privacy and user autonomy is a core principle of this application.

## 1. No Personal Data Collection

TransVoice does not collect, process, store, transmit, or share any personal data.

This includes, but is not limited to:

- Names or usernames
- Email addresses
- Phone numbers
- Location data
- IP addresses
- Device identifiers
- Usage analytics
- Telemetry data
- Voice recordings
- User-generated content

## 2. No Account Required

TransVoice can be used without creating an account.

The application does not require:

- User registration
- Login credentials
- Cloud accounts
- Online profiles

## 3. Local Storage Only

All settings, preferences, training data, and other application data are stored exclusively on the user's device.

No data is uploaded to external servers, and all information remains under the full control of the user at all times.

## 4. No Advertising

TransVoice does not display advertisements.

The application does not use:

- Advertising networks
- Advertising identifiers
- Tracking technologies
- Marketing analytics
- User profiling

## 5. No Third-Party Data Sharing

Because TransVoice does not collect personal data, no personal information is sold, shared, transferred, or disclosed to any third party.

## 6. Data Security

As no user data is transmitted to external services and all information remains stored locally on the device, users maintain direct control over their data.

## 7. User Rights

Since no personal data is collected or processed by the Rainbow Library, there are no user databases containing personal information that can be accessed, modified, or deleted.

Users may remove all locally stored data at any time by deleting the application or clearing its local storage.

## 8. Contact

If you have questions regarding this Privacy Policy or the privacy practices of TransVoice, please contact the Rainbow Library through its official communication channels.

## 9. Changes to This Privacy Policy

Should future versions of TransVoice introduce features that require the processing of personal data, this Privacy Policy will be updated accordingly and users will be informed of any material changes.

---

### Summary

TransVoice does not collect personal data, does not require user accounts, does not display advertising, does not use tracking technologies, and stores all data locally on the user's device under the user's full control.
